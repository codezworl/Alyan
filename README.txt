  signature-plain.txt                                        -> text version for the Gmail phone app

STEPS
1. Copy all 5 files into your portfolio project's public/email/ folder.
2. Deploy to Vercel.
3. Open these three links in a browser. Each must show an image, not a 404:
   https://alyan-mu.vercel.app/email/logo-as-192.png
   https://alyan-mu.vercel.app/email/icon-linkedin-64.png
   https://alyan-mu.vercel.app/email/icon-github-64.png
4. Open https://alyan-mu.vercel.app/email/signature.html in Chrome (the live page, not the file on your computer).
5. Press Ctrl+A, then Ctrl+C.
6. Gmail: gear icon > See all settings > General > Signature. Delete the old signature, paste, Save Changes.
7. Send a test to a DIFFERENT Gmail account and check desktop, phone, and dark mode.
